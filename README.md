# spasibo

Одностраничка с благодарностями для отправки ссылкой в стиле веб-брутализма.

## Локально

Из этой папки:

```bash
python3 -m http.server 8080
```

Открыть [http://localhost:8080](http://localhost:8080).

Или:

```bash
npx --yes serve .
```
